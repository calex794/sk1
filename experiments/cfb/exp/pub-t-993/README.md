# PUB-T-993 — реальный Writer переносит высокий исходный SYID через 0x400

[Каноническая задача в Notion](https://app.notion.com/p/3f632a84beec81b1947ced763218aec9)

**Исходный настоящий PUB**: `ADatumNews.pub` из зафиксированного MicrosoftPress Publisher 2007 SBS ZIP, точный SHA-256 `b4b005a7e6f662546cf07bdd155a1cf936293e6ceb6ac7f424456fee87051f1b`, длина 471 552 байта. Естественный подтверждённый `Quill/SYID.header=1009 = 0x3F1`, `SYID.count=65`, max live ID=965. Эти значения **доказаны независимым PUB-T-992** ([Notion](https://app.notion.com/p/3f632a84beec81d5a716e797ecec7385)) и не исправляются.

Второе, новое относительно PUB-T-988 исследование: тот выполнял три пары Writer из оригинального FA (250) до Writer-generated FE и 0x100. Здесь **другой оригинал уже содержит высокий 0x3F1**; проверяются до **восьми** последовательных Writer inverse pairs `insert→delete` на каждом из максимум трёх заранее подходящих Story, чтобы получить через настоящие Writer materializations конечные натурально-счётные (но Writer-created) состояния `0x3F3,0x3F5,0x3F7,0x3F9,0x3FB,0x3FD,0x3FF,0x401`. В 8-й паре настоящий Writer должен (если допустит) последовательно выполнить `0x3FF→0x400→0x401` и изменить **2 little-endian байта** первого DWORD SYID, не меняя больше ни одного raw PUB byte.

## Ограничение и повторное использование

- Источник оригинала берётся только через проверенную PUB-T-992 программу `retrieve_package()`, закреплённую при научном SHA `cfcce7f3f9c425210ee28265d4dbdf79bf742dcc`, без новой реализации ZIP загрузчика. Оригинальный учебный архив содержит строго 13 зарегистрированных PUB с SHA/size; все 13 повторно проверяются в отдельном **невключаемом в артефакт** каталоге `source-stage`. Единственный целевой SHA выбран заранее, не после Writer guard.
- Реальный Writer/Reader/Editor/CFB — строго `Lalalalendia/rar2@703808408fd919e564a90cdc236e81db3c04af8b`, **без изменений**. Исследовательские `step`, `physical_residue`, `inspect_reverted_cfb` копируются строго из испытанного T984/T963 writer-probe во временный Rust example через тот же скрипт `prepare.py`, что применён в PUB-T-988. Новый код только последовательно вызывает прежний Writer на текущих PUB байтах и считает безопасные квитанции. Никакой прямой замены header SYID.
- Выбор Story детерминирован на оригинале: максимум первые три в Quill original ordinal с `Editor.can_replace_story_text` и как минимум двумя ASCII буквенно-цифровыми символами, фиксированный второй ASCII и один безопасный иной ASCII marker. Не изменять позицию и Story при guard-отказе.
- После каждого Writer шага — Reader reopen, полная проверка нетаргетных Story и byte-equal EditorProject replay. После каждого завершённого цикла — абсолютный побайтовый diff всего PUB относительно начала цикла и исходного оригинала, сравнение всех CFB потоков, Quill TEXT/Story/SYID, числовой counter `+2` и фактическое число отличающихся little-endian байтов. При Writer guard дальнейшие циклы той Story не запускаются, ошибки и контрпримеры фиксируются, но не обходятся.
- Научный результат `PASS` только для тех Story, где все восемь циклов действительно прошли. `INCOMPLETE` при блокировке остаётся полезным отрицательным условным исходом. Три исходные Story не означают три независимых Publisher-документа: **исходник ровно один**.

## Безопасность и критерий закрытия

Никаких исходных или Writer-промежуточных PUB, Quill raw, текста Story, URL учебного архива или stderr в GitHub artifact. Ровно **plan.json, records.json, report.json** со source-SHA, числовыми счётчиками, Quill/CFB результатами. Независимый checker заново хеширует все 13 временных первичных PUB, сверяет source/T992 pin, использует прежний T963 независимый валидатор Writer Step/CFB; на каждом цикле воспроизводит модель точных raw bytes. Затем исходный ZIP артефакт скачивается отдельно, SHA256/CRC и per-cycle summary перепроверяются, знание и verdict немедленно сохраняются в Notion. Только metadata-row попадает в `sk1/main`.

Нативный Microsoft Publisher Open/SaveAs **не проверяется**; если будет достигнуто `0x3FF/0x401`, это будут **Writer-generated состояния**, не оригинальные Publisher saved files. Название пакета обучения — происхождение, а не удостоверение точной версии сериализатора.
