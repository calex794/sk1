# PUB-T-978 — управляющие символы и разделители в Quill Writer

[Каноническая задача в Notion](https://app.notion.com/p/3f632a84beec813883d6e1687eb961a3).

## Отдельная гипотеза

PUB-T-961 проверяла 4 печатных BMP-символа и один астральный U+1F600. Здесь исследуются **семь других одноединичных UTF-16 кодов** с последствиями для абзацев, переносов и табуляции. Сравнение проводится с ASCII-кандидатом на **том же исходном SHA/Story/UTF16 offset**. Изменения вне вставленного UTF-16 code unit считаются отдельным контрпримером. Отказы Writer сохраняются без обхода.

| Тег | Unicode | Смысл |
|---|---|---|
| NUL | U+0000 | Нулевой код |
| TAB | U+0009 | Табуляция |
| LF | U+000A | Перевод строки |
| VT | U+000B | Вертикальная табуляция |
| CR | U+000D | Маркер абзаца (ожидаемый Writer-guard) |
| NBSP | U+00A0 | Неразрывный пробел |
| LINE_SEPARATOR | U+2028 | Разделитель строки |

Входы: ровно **13** публичных SHA и **77** заранее удостоверенных мест из T961: SHA256 неизменяемого `witnesses.json` = `c7a74f2fe7e1f72b4400628705d9f5eb7640ba95c9a1ff5b8292bddd579d904b`. Это **77 повторных измерений на 13 исходных документах, не 77 независимых PUB**.

Вызываются 77 исходных ASCII контролей и **539** отдельных Writer попыток по новой матрице. Каждый PASS требует Reader reopen, сохранности соседних Story/SYID и побайтового EditorProject replay, затем сравнения полного CFB и Quill/UTF16 только со своим ASCII-контролем.

## Без дублирования

Здесь коммитятся только `prepare.py`, текущий README, workflow и запись в реестре. `prepare.py` получает **точный** рабочий код T961 на научном коммите `9ca16fa981e9fd516822979491654eb9b0fc9264`, проверяет четыре blob-SHA (3 программы + witnesses) и заменяет строго матрицу из 7 символов, идентификатор эксперимента и формат provenance. Код родительского Reader/Writer/CFB сравнения **не переписывается** и не сохраняется как постоянная копия. Подключается оригинальный `Lalalalendia/rar2@703808408fd919e564a90cdc236e81db3c04af8b` без изменений.

[GitHub Actions](https://github.com/calex794/sk1/actions/workflows/sk1-quill-val-pub-t-978.yml). Публикуются только три безопасных JSON (числа, SHA, статусы, коды), без PUB или текста. Результат касается только закреплённого Writer; он не доказывает соответствие Microsoft Publisher, отображение/сохранение абзацев или разрешение продуктового Save.
